# 01 · 面试的一般原则

<SourceNote :start="1" :end="2" section="Chapter 1" />

量化面试通常同时考查知识基础与解题过程。原书用五条原则说明如何让已有知识真正转化成可交流、可检验的答案：掌握基础，提前练习，听清问题，表达思路，说明假设。

## 建立宽而扎实的知识基础

面试题可能跨越逻辑、微积分、线性代数、概率、衍生品与编程。作者强调对核心概念的理解：知道公式为什么成立、需要什么条件，才能把它用于没有见过的问题。

本书的技术主线可以沿下面的依赖关系阅读。逻辑题训练的方法会在概率递推、动态规划和算法中反复出现。

## 练习面试中的表达

把一道题独立做完，再口头解释一遍，往往会暴露不同的问题：纸上计算可能正确，但没有说明状态为什么足够；公式可能熟悉，但无法解释边界条件。

原书建议提前准备技术、行为和履历相关的问题。用于本书的练习方式是：先遮住解答尝试建模，再对照推导，最后改变一个条件，检查原来的方法还能否使用。这一练习安排是本站的学习建议。

## 先听清问题

概率题中的抽样方式、博弈题中的投票门槛、算法题中的输入限制，都会改变答案。把题意转成明确条件后，再开始求解。

| 需要澄清的对象 | 会改变答案的条件 |
| --- | --- |
| 随机试验 | 是否独立、是否等可能、是否放回 |
| 优化目标 | 期望最好、最坏情况最好，还是成功概率最高 |
| 游戏规则 | 先后顺序、平票是否通过、能观察哪些信息 |
| 计算任务 | 数据规模、是否已排序、是否允许额外空间 |

## 让推理过程可见

先说明打算使用的结构，再展开计算。例如在赌徒破产题里，先定义“从资金状态 $i$ 出发，先到达 $N$ 的概率”，然后写转移方程和两个边界值。这样即使运算尚未完成，讨论对象也已经明确。

原书并不要求解释每一个算术步骤。表达应集中在关键选择：为什么能用对称性、为什么条件化后变简单、为什么这个递推没有遗漏状态。

## 提出并说明合理假设

缺少条件时，明确说出你的假设，并说明结论对它的依赖。例如，生日问题采用“365 天等概率、生日独立、忽略闰年”的模型；Black–Scholes 推导则需要说明波动率、交易与标的动态的假设。

面试中的有效回答可以按以下顺序组织：

1. 复述目标并确认条件。
2. 定义变量、状态或样本空间。
3. 用小例子、边界或对称性建立直觉。
4. 给出推导，并检查单位、范围和极端情况。
5. 说明改变条件后需要重新检查哪一步。

这五步是对原书原则的学习化整理。进入[第二章](../02-brain-teasers/overview.md)，可以直接练习这种表达方式。
